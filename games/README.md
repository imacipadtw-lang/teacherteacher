# 課前課後診斷遊戲

| 單元 | 年級 | 前測遊戲 | 後測遊戲 | 網址 |
|---|---|---|---|---|
| 巴黎迷路大冒險 | 五年級 | 巴黎卡丁車 | 可頌忍者 | https://imacipadtw-lang.github.io/teacherteacher/games/paris-g5/ |
| 維也納音樂之旅 | 六年級 | 音樂寶箱轉蛋 | 樂團找內鬼 | https://imacipadtw-lang.github.io/teacherteacher/games/vienna-g6/ |

## 流程

1. 學生點前測或後測遊戲 → 選座號 → 作答 8 題。
2. 玩完畫面出現一組代碼（例如 `P1-07-ABDCABDA`），請學生抄下來或拿給老師看。
3. 老師從首頁右下角進入「教師分析表」，班級欄填班級（例如 601），把代碼貼進去按「匯入代碼」。
4. 按 **⬇️ 下載成績檔**（每人一列）或 **⬇️ 下載作答明細**（每人每題一列，含他選了什麼選項、那個選項代表什麼迷失），CSV 檔用 Excel 打開。
5. 表二每位學生右邊的 **🔎 看作答** 可以直接在畫面上看他每一題的作答。

## 注意

學生的作答存在「他自己那台裝置」的瀏覽器裡。全班用各自平板玩時，老師那台不會自動收到資料，要靠學生回報代碼匯入；全班輪流用同一台裝置玩，資料就會直接累積在那台。
